# Compliance Rules

## Data Privacy
- PII must be encrypted at rest and in transit
- Implement data retention policies (max 90 days for logs)
- Support GDPR data deletion requests
- Provide audit trails for all data access

## Accessibility
- WCAG 2.1 AA compliance required for all UI
- Support screen readers and keyboard navigation
- Color contrast ratio must meet WCAG standards
- All images must have alt text

## Licensing
- Ensure all dependencies have compatible licenses
- Maintain LICENSE file in each repository
- Attribute third-party code as required
