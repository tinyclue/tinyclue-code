# User Global Configuration

Personal preferences and global instructions for all projects.

## Communication Style
- Provide concise, direct answers
- Use code examples where appropriate
- Explain the reasoning behind important decisions
- Prefer simple solutions over clever ones

## Coding Preferences
- Use tabs for indentation (width: 2)
- Maximum line length: 120 characters
- Prefer functional programming patterns
- Use descriptive variable names (no single-letter names except loop indices)

## General Workflow
- Always check for existing tests before writing new ones
- Update documentation when changing behavior
- Run linter before committing changes
- Write commit messages in conventional commits format
