# Editor and Tool Preferences

## IDE Settings
- Use VS Code with the following extensions:
  - ESLint, Prettier, Go, Rust Analyzer
- Format on save enabled
- Auto-import on completion
- Show git blame annotations

## Terminal
- Use zsh with oh-my-zsh
- Preferred shell: bash for scripts
- Use tmux for session management

## Git
- Use rebase workflow (not merge commits)
- Branch naming: `<type>/<description>` (e.g., `feat/add-login`)
- Sign commits with GPG
