# Additional Directory Rules

## Shared Library Guidelines
This directory contains shared libraries used across multiple projects.

## Library Standards
- All shared libraries must have comprehensive README
- Public API must be stable and versioned
- Breaking changes require deprecation notice for one release cycle
- Maintain backward compatibility where possible

## Documentation
- Document all public types, functions, and constants
- Include usage examples in docstrings
- Keep CHANGELOG.md up-to-date
